## About

I build small tools that do one job, ship them, and keep them running.

Most of what I make started as a problem I hit myself: a ticket that sold out before I could click, a results PDF nobody wanted to read, notes I needed answers from at 2am. I put AI where it earns its place and write plain code for everything else.

Recent work:

Lens, a desktop AI assistant for macOS and Windows that reads your screen and follows your calls, answering from your own documents. The model runs on your own machine, so it costs nothing to use and nothing leaves your computer. It reads your hardware and recommends a model that will actually run on it, and can offload inference to another machine on your network.

Ask My Docs, a retrieval system that answers from your PDFs with citations back to the exact source passage, using vector search and embeddings that run in the browser.

SiteSage, an embeddable AI chat widget any site can add with one script tag, multi-tenant so a single deployment serves every customer.

Exam Toolkit, free revision tools for Edexcel International A Level and IGCSE, built from every published grade boundary.

I work in Python and TypeScript, with React, Next.js, Electron and Postgres, and I have shipped against Anthropic, Gemini, OpenAI, Groq and locally hosted models.

Everything is public: github.com/erfanulfarhan
Portfolio: erfanulfarhan.vercel.app

## Projects section  (add each separately)

**Lens — Local-first AI desktop assistant**
Associated with: personal project
A screen and audio aware assistant for macOS and Windows. Answers from your own documents using retrieval, transcribes calls on-device, and runs the model on hardware you control, with optional support for any API key you already own. Detects your RAM and VRAM to recommend a model that will run smoothly. Built with Electron, React, TypeScript and Swift, with installers for both platforms.
Link: https://github.com/erfanulfarhan/lens

**SiteSage — Embeddable AI chat widget**
A multi-tenant chat widget any website can add with one script tag. Train a bot on pasted text or web pages; retrieval runs on Postgres full-text search.
Link: https://sitesage-erfanul.vercel.app

**Ask My Docs — RAG knowledge base with citations**
Ask questions of your own PDFs and notes and get answers with citations to the exact source passage. Semantic vector search on Supabase pgvector, with embeddings computed in the browser.
Link: https://ask-my-docs-erfanul.vercel.app

**Exam Toolkit — Revision tools for Edexcel IAL and IGCSE**
A UMS grade calculator built from every published grade boundary, past papers beside mark schemes that stay locked until you attempt the question, a mock timer and a study planner.
Link: https://edexcel-grade-calc.vercel.app

**Slate — File storage with expiring share links**
Passwordless email sign-in, drag and drop upload, browse by type. Download links are minted per request and expire, so a shared URL stops working instead of living forever.
Link: https://store-it-c-e113.vercel.app

**Cineplex Automation — Real-time cinema seat tracking**
A Telegram bot and web app that track seat availability live, render seat maps, and place standing orders that book the moment tickets go on sale. Python and Playwright.
Link: https://github.com/erfanulfarhan/cineplex-bot
